# Параллельность плоскостей — шпора

**α ∥ β** ⇔ нет общих точек. Два случая: **пересекаются по прямой** (α ∩ β = a) или **параллельны**.
**A₃:** общая точка ⇒ общая прямая.

## Признак ∥ плоскостей
**Две пересекающиеся** прямые одной плоскости ∥ двум прямым другой ⇒ α ∥ β.
```
a ∩ b = O, a,b ⊂ β
a1 ∩ b1 = O1, a1,b1 ⊂ α   ⇒  α ∥ β
a ∥ a1, b ∥ b1
```
⚠ Нет слова «две» или «пересекающиеся» → **неверно**, контрпример на **кубе**.

## Свойство = признак ∥ прямых
α ∥ β, γ ∩ α = a, γ ∩ β = b ⇒ **a ∥ b**.

**3 признака ∥ прямых:** ① две ∥ третьей; ② плоскость через прямую ∥ другой плоскости → линия пересечения ∥ прямой; ③ ∥ плоскости пересечены третьей.

## Типовые ответы
| Вопрос | Ответ |
|---|---|
| Одна пара ∥ прямых → плоскости ∥? | **Нет** (BC ∥ A₁D₁, но (ABCD) ∩ (AA₁D₁D) = AD) |
| Две пары ∥ прямых → ∥? | **Нет**, если прямые ∥ (AA₁ ∥ CC₁, MM₁ ∥ NN₁; грани ∩ по BB₁) |
| ∥ плоскости через непараллельные прямые? | **Да** (основания куба) |
| Плоскости ∥ одной прямой могут пересекаться? | **Да** (CC₁ ∥ передней и левой граням) |
| Плоскость через точку ∥ данной — сколько? | **Одна**: b₁ ∥ a₁, b₂ ∥ a₂ через точку → признак |
| В ∥ плоскостях все прямые ∥? | **Нет**, бывают скрещивающиеся |

# Тетраэдр и сечения — шпора

**Тетраэдр** = треугольная пирамида: 4 грани-треугольника, 6 рёбер, 4 вершины (тетра = 4, эдра = грань).
**Правильный** — все рёбра равны (все грани — равносторонние треугольники).
**Куб** — частный случай прямого параллелепипеда.

**Секущая плоскость** — бесконечная плоскость; **сечение** — **многоугольник** на фигуре.

## 3 этапа задачи
1. **Построить** (по шагам).
2. **Доказать** (признаки).
3. **Назвать** многоугольник и его вид.

## Правила построения
- Соединять только точки **одной грани**.
- Плоскость ∥ ребру → в грани с этим ребром проводим прямую **∥ ребру**.
- **Доказательство:** прямая сечения ⊂ α и ∥ ребру ⇒ ребро ∥ α (признак ∥ прямой и плоскости).

## Задания урока
| Условие | Шаги | Сечение |
|---|---|---|
| ∥ AD, E ∈ BC, F ∈ DC | FE; FG ∥ AD (G ∈ AC); GE | **△FGE** |
| ∥ CD, F ∈ AD, E ∈ BC (скрещ.) | FH ∥ CD (H ∈ AC); EG ∥ CD (G ∈ BD); FG; HE | **четырёхугольник FGEH** (FH ∥ GE → трапеция) |

## Сечения тетраэдра
4 грани → **только △ или четырёхугольник**, 5- и 6-угольник **нельзя**.
Правильный тетраэдр: правильный, равнобедренный, разносторонний △; прямоугольник, квадрат, равнобедренная трапеция.
