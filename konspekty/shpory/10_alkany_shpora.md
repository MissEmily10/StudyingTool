# Алканы — шпора к самостоятельной

**Алканы** = только C и H, все связи **одинарные**. Формула **CₙH₂ₙ₊₂**. Суффикс **-ан**. Углерод всегда имеет **4 связи**.

| n | Цепь | Формула | M, г/моль |
|---|---|---|---|
| 1 | **мет**ан | CH₄ | 16 |
| 2 | **эт**ан | C₂H₆ | 30 |
| 3 | **проп**ан | C₃H₈ | 44 |
| 4 | **бут**ан | C₄H₁₀ | 58 |
| 5 | **пент**ан | C₅H₁₂ | 72 |
| 6 | **гекс**ан | C₆H₁₄ | 86 |
| 7 | **гепт**ан | C₇H₁₆ | 100 |
| 8 | **окт**ан | C₈H₁₈ | 114 |
| 9 / 10 | **нон**ан / **дек**ан | C₉H₂₀ / C₁₀H₂₂ | 128 / 142 |

M алкана = **14n + 2**. «**М**ама **Е**ла **П**ирожки **Б**ыстро» = мет, эт, проп, бут.

## 1. Название по формуле
Ветки: **–CH₃ метил**, **–C₂H₅ этил**, –C₃H₇ пропил. Две одинаковые — **ди**, три — **три**, четыре — **тетра**.
1. **Самая длинная цепь C**. Можно поворачивать в ветку! Если ветка стоит на краю цепи, она её удлиняет.
2. **Нумерация** с того конца, где **ветка ближе**. Если ветки на одинаковом расстоянии, выбирай, где **меньше номера** при первом различии.
3. **Пишем:** номера через **запятую**, номер и слово через **дефис**, всё слитно. Номер повторяем для **каждой** ветки (2,2-…). Разные ветки — по алфавиту (метил → этил).
4. **Проверка:** C в названии = C в формуле.

**Пример (как в самостоятельной):**
```
        CH3
        |
H3C—CH2—C—CH2—CH—CH2—CH3
        |     |
        CH3   CH3
```
Цепь 7 C → **гептан**. Слева ветки на 3,3,5, справа — на 3,5,5. При первом различии 3 < 5, значит, нумеруем слева.
→ **3,3,5-триметилгептан** (7 + 3 = 10 C, **C₁₀H₂₂**).

## 2. Формула по названию + изомеры
1. Корень → нарисовать цепь (гекс = 6 C), пронумеровать.
2. На нужные номера повесить ветки.
3. Дописать H так, чтобы у каждого C было 4 связи: на конце CH₃, в середине CH₂, с одной веткой CH, с двумя C.

**2,4-диметилгексан** (6 + 2 = 8 C, **C₈H₁₈**):
```
CH3—CH—CH2—CH—CH2—CH3
    |      |
    CH3    CH3
```
**Изомеры** — **та же формула** (C₈H₁₈), **другой скелет**. Перекладываем те же 8 C по-другому:
- **октан** CH3—CH2—CH2—CH2—CH2—CH2—CH2—CH3
- **2,5-диметилгексан**: CH3—CH(CH3)—CH2—CH2—CH(CH3)—CH3
- ещё подходят: 2-метилгептан, 3-этилгексан, 2,2,4-триметилпентан.

**Гомологи** ≠ изомеры: отличаются на CH₂ (метан, этан, пропан…).

## 3. Химические свойства (как работают)

| Реакция | Суть | Условия | Пример |
|---|---|---|---|
| **Горение** (+O₂) | Сгорает весь скелет → CO₂ + H₂O | поджечь | C₃H₈ + 5O₂ → 3CO₂ + 4H₂O |
| **Галогенирование** (+Cl₂ / Br₂) | **Замещение**: 1 H меняется на галоген, «выпавший» H уходит в HCl/HBr | **свет hν** | CH₄ + Cl₂ → CH₃Cl + HCl |
| **Дегидрирование** (−H₂) | Отрывают 2 H → двойная связь → **алкен** (-ан → **-ен**) | t, кат. **Ni / Pt** | C₂H₆ → C₂H₄ + H₂ |
| **Пиролиз** метана (разложение) | Сильный нагрев разбивает на сажу и H₂ (или на ацетилен) | **1000 °C** / 1500 °C | CH₄ → C + 2H₂ ; 2CH₄ → C₂H₂ + 3H₂ |
| **Крекинг** | Длинная цепь ломается пополам → алкан + алкен | t, кат. | C₈H₁₈ → C₄H₁₀ + C₄H₈ |
| **Изомеризация** | Прямая цепь → разветвлённая, формула та же | t, кат. **AlCl₃** | бутан → 2-метилпропан (изобутан) |
| **Нитрование** (р. Коновалова) | Замещение H на –NO₂ | разб. HNO₃, t | CH₄ + HNO₃ → CH₃NO₂ + H₂O |

### Горение: как уравнять (всегда так)
1. **C** → столько CO₂, сколько атомов C.
2. **H** → H₂O = H : 2.
3. **O** → посчитать O справа → O₂ = это число : 2.
4. Получилась дробь → **умножить всё на 2**.

**Примеры:**

- Бутан: C₄H₁₀ → 4CO₂ + 5H₂O, O = 8 + 5 = 13 → 6,5 O₂ → **2C₄H₁₀ + 13O₂ → 8CO₂ + 10H₂O**.
- Общая формула: CₙH₂ₙ₊₂ + **(3n+1)/2** O₂ → nCO₂ + (n+1)H₂O.
- Мало O₂ → **неполное горение**: CO (угарный газ) или C (сажа).

### Галогенирование: что запомнить
- Название продукта: **хлор/бром + алкан**: хлорметан, бромэтан, 2-бромпропан.
- Можно **дальше**: CH₃Cl → CH₂Cl₂ → CHCl₃ → CCl₄ (каждый раз + Cl₂, − HCl).
- У пропана и длиннее H легче всего заменяется у C **с меньшим числом H** (у CH, затем у CH₂, хуже всего у CH₃). Пропан + Br₂ → **2-бромпропан** + HBr.

### Дегидрирование: что запомнить
- Этан → **этен** (этилен) C₂H₄; пропан → пропен C₃H₆; бутан → бутен C₄H₈ (или до бутадиена C₄H₆ + 2H₂).
- В уравнении **всегда** справа + H₂.

## 4. Расчётные задачи (по уравнению)
**Формулы:** **n = m / M**, **n = V / 22,4** (газ, н. у.), **m = n · M**, **V = n · 22,4 л**.
Атомные массы: **C = 12, H = 1, O = 16, Cl = 35,5, Br = 80**. M(CO₂) = 44, M(H₂O) = 18, M(H₂) = 2, M(O₂) = 32.

**Алгоритм (5 шагов):**
1. Уравнение с коэффициентами.
2. n дано = m : M (или V : 22,4).
3. n искомого = n дано × (коэф. искомого : коэф. данного).
4. m = n · M **или** V = n · 22,4.
5. Ответ с единицами (г или л).

**Вариант 1.** m(CO₂) при горении **92 г пропана**:
C₃H₈ + 5O₂ → 3CO₂ + 4H₂O
n(C₃H₈) = 92 : 44 ≈ 2,09 моль → n(CO₂) = 3 · 2,09 ≈ 6,27 моль → m = 6,27 · 44 ≈ **276 г**.
(Удобно: M(C₃H₈) = M(CO₂) = 44, поэтому m(CO₂) = 3 · 92 = 276 г ровно.)

**Вариант 2.** V(H₂) при дегидрировании **45 г этана**:
C₂H₆ → (t, Ni) C₂H₄ + H₂
n(C₂H₆) = 45 : 30 = 1,5 моль → n(H₂) = 1,5 моль (1 : 1) → V = 1,5 · 22,4 = **33,6 л**.

## ⚠ Ловушки
- В уравнении между веществами слева **«+»**, а не «−»: C₃H₈ **+** 5O₂.
- C₇H₁₆ — это не «гексан»: 7 C = **гептан**. Название цепи — по числу C в **главной** цепи, а не по всей молекуле.
- В названии **всегда нужен номер** ветки: «**2**-метилбутан», «**3**-этилпентан».
- **Галогенирование** — замещение (+HCl справа); **дегидрирование** — отщепление (+H₂ справа).
- Объём через 22,4 считают **только для газов**.
