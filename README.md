# StudyTool — конспекты школьных вебинаров

Веб-приложение, которое:

1. **заходит на вебинар MTS Link** как участник (по ссылке на комнату, сразу или по расписанию) и записывает звук;
2. **распознаёт речь** учителя прямо на сервере (бесплатно; при желании — облачный Whisper API);
3. **передаёт расшифровку Claude** через этот репозиторий (папка `lessons/`) — конспект пишет Claude в обычной подписке, без платного API (правила — в [CLAUDE.md](CLAUDE.md)); можно и через Claude API (`SUMMARY_MODE=api`). В конспекте: главная мысль, все детали урока с таймкодами, что задали, дополнительные полезные факты, вопросы для самопроверки;
4. учитывает **материалы урока** (PDF-презентацию по ссылке из электронного журнала или файлом);
5. отдаёт конспект **PDF для печати** (две страницы A5 на листе A4) и в Markdown; конспект можно поправить прямо на сайте.

Если записи нет, можно загрузить свой файл записи (аудио или видео) или сделать конспект только по презентации.

## Что нужно

| | Зачем | Где взять |
|---|---|---|
| **Сервер** (VPS) | Бот, сайт и распознавание речи | Ubuntu 22.04/24.04, **4 vCPU, 4–8 ГБ RAM, 30 ГБ диска** (на 2 vCPU распознавание идёт примерно вдвое медленнее) |
| **Токен GitHub** | Сервер кладёт расшифровки в `lessons/` и забирает готовые `konspekt.md` | github.com → Settings → Developer settings → Fine-grained tokens, доступ Contents: Read and write к этому репозиторию |

Распознавание речи идёт на самом сервере (faster-whisper, модель large-v3-turbo уже внутри образа): бесплатно, но урок распознаётся примерно за то же время, сколько он длился (на 4 ядрах ~0,75 от длины урока). Если нужно быстрее — в `.env` можно включить облачный Whisper API (`TRANSCRIBE_PROVIDER=api`).

> Режим `SUMMARY_MODE=api` (сервер сам вызывает Claude API) требует ключ Claude API и доступен не во всех странах.
> Сервер должен открывать `my.mts-link.ru`: проверьте командой `curl -I https://my.mts-link.ru` на сервере.

## Установка на сервер (≈15 минут)

**Быстрый путь:** пошаговый план с ценами — [SETUP.md](SETUP.md). На сервере достаточно одной команды:

```bash
curl -fsSL https://raw.githubusercontent.com/MissEmily10/StudyingTool/master/install.sh | bash
```

Или вручную:

```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh

# 2. Код
git clone https://github.com/MissEmily10/StudyingTool.git
cd StudyingTool

# 3. Настройки: впишите пароль, имя для бота и ключи
cp .env.example .env
nano .env

# 4. Запуск (первый раз собирается ~10 минут: скачивается Chromium и модель распознавания)
docker compose up -d --build
```

Откройте `http://IP-сервера:8000`, браузер спросит логин и пароль из `.env`.

Обновление после изменений в коде: `git pull && docker compose up -d --build`.
Логи: `docker compose logs -f`. Все уроки и записи лежат в папке `data/`.

## Как пользоваться

- **Перед уроком:** «Новый урок» → предмет, тема, ссылка на комнату MTS Link → «зайти сейчас» или время начала. Бот зайдёт за 2 минуты до начала.
- **Во время урока:** на странице урока виден статус и **скриншот того, что видит бот** (обновляется сам). Если что-то пошло не так — там будет видно, на каком шаге он застрял.
- **После урока:** бот останавливается сам, когда эфир завершён (или после 10 минут тишины, или вручную кнопкой «Остановить»). Конспект появляется примерно через час после урока для полуторачасового урока (распознавание + конспект); уроки обрабатываются по очереди.
- **Материалы:** вставьте ссылку на PDF из электронного журнала — презентация будет учтена в конспекте.
- **Заметки:** в поле «Что задали» можно написать, что учитель просил выучить, — это попадёт в конспект.

## Как это устроено

```
app/
  main.py        веб-интерфейс (FastAPI), вход по паролю
  recorder.py    бот: Chromium (Playwright) заходит в комнату, жмёт кнопки входа, пишет звук
  capture.js     перехват звука внутри страницы (WebRTC и <audio>/<video>) → MediaRecorder
  transcribe.py  аудио → текст с таймкодами (Whisper API или faster-whisper)
  sync.py        обмен с GitHub: lessons/<урок>/transcript.txt → konspekt.md
  summarize.py   текст + PDF → конспект через Claude API (режим SUMMARY_MODE=api)
  printing.py    конспект → PDF A5×2 на A4
  pipeline.py    расписание, очередь обработки
tests/           проверка бота на имитации вебинара и всего приложения
```

Проверки (нужен Chromium и ffmpeg):

```bash
python -m tests.test_recorder   # бот: вход по имени, запись WebRTC-звука, остановка по концу эфира
python -m tests.test_app        # приложение целиком (распознавание и Claude подменены заглушками)
python -m tests.test_sync       # режим без API: обмен расшифровками и конспектами через git
```

## Известные ограничения

- Вход в комнату MTS Link проверен на имитации; интерфейс настоящей комнаты может потребовать доработки кнопок входа. Для этого и сохраняется скриншот бота.
- Если организатор требует регистрацию или вход в аккаунт MTS Link, бот пока это не умеет.
- Бот виден в списке участников под именем из `BOT_NAME`.
- Используйте записи и конспекты только для своей учёбы, не публикуйте их.
