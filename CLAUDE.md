# StudyTool

Сервер (папка `app/`, см. README) записывает школьные вебинары и распознаёт речь. Конспекты пишет Claude в обычной подписке — без API: сервер кладёт урок в `lessons/<дата>_<id>_<предмет>/`, Claude пишет рядом `konspekt.md`, сервер раз в несколько минут забирает его из ветки `master`.

## Задача «сделай конспекты»

1. `git pull origin master`. Найди папки `lessons/*/`, где есть `meta.json`, но **нет** `konspekt.md`.
2. Для каждой прочитай:
   - `meta.json` — предмет, тема, учитель, дата, `notes` (что задали / на что обратить внимание);
   - `transcript.txt` — речь учителя с таймкодами `[мм:сс]`, распознана автоматически: исправляй очевидные ошибки распознавания по смыслу, действительно непонятное помечай «(неразборчиво)»;
   - `materials.pdf`, если есть, — презентация урока. Сканы читай как картинки (`pdftoppm -r 70 -png`, смотри страницы), мелкие таблицы — в большем разрешении.
3. Напиши `konspekt.md`, `shpora.md`, `quiz.json` и `videos.md` по правилам ниже.
4. Закоммить и **запушь прямо в `master`** (`git push origin HEAD:master`) — сервер берёт конспекты только оттуда; так задумано владельцем репозитория. При конфликте — `git pull --rebase origin master` и снова push.
5. Если новых уроков нет — ничего не делай и не создавай пустых коммитов.

## Правила конспекта

- Сохрани **все** содержательные детали урока: определения, даты, имена, формулы, примеры, причины и следствия, выводы. Отдельно — что учитель назвал важным, «будет на контрольной», что задал.
- Не выдумывай того, чего не было на уроке. Всё, что добавляешь сверх урока, — только в раздел «💡 Дополнительно».
- В «💡 Дополнительно» — полезные факты, пояснения, мнемоники, типичные ловушки в тестах. Факты, в которых не уверен, **проверь поиском в интернете**. Ссылки на источники не вставляй.
- **Нигде не упоминай ИИ**, нейросети, Claude, «расшифровку», «распознавание», «автоматически» — конспект выглядит как написанный самим учеником.
- Язык — русский. Иностранный язык: объяснения по-русски, примеры на изучаемом языке (свои примеры, не переписывай учебник).
- Сравнения, хронологии, классификации — таблицами Markdown. Ключевые термины — **жирным**.
- У разделов, взятых из речи учителя, — таймкод начала: `## 2. Пептидная связь (14:20)`.

Структура (строго в этом порядке):

```
# <Предмет>. <Тема урока>
**<класс · преподаватель · дата — что известно>**

---

## ⭐ Главная мысль
2–4 предложения: о чём урок и как связаны его части.

## 1. … (мм:сс)
…подробный конспект по ходу урока…

## 📝 Задано
(только если прозвучало или есть в notes)

## 💡 Дополнительно

## ✅ Вопросы для самопроверки
8–12 вопросов.
```

Образцы оформления — `konspekty/*.md`.

## Правила шпоры (`shpora.md`)

Сжатая выжимка всего урока для печати на A6/A7 (мелко, 1–2 страницы A6): только то, что нужно вспомнить на контрольной.
- Заголовок `# <Тема> — шпора`, дальше короткие `##` разделы.
- Определения — одной строкой, даты/формулы/правила — таблицами, ключевое — **жирным**, стрелки `→` вместо фраз.
- Без вступлений, пояснений «зачем» и вопросов для самопроверки. Можно 1–2 мнемоники.
- Те же запреты, что для конспекта (никаких упоминаний ИИ, без ссылок).

Образцы — `konspekty/shpory/*_shpora.md`.

## Тест (`quiz.json`)

8–10 вопросов по материалу урока — их бот присылает как викторины Telegram. Строго такой JSON:

```json
[
  {"question": "Чему равна сумма углов треугольника?", "options": ["90°", "180°", "360°"], "correct": 1,
   "explanation": "Сумма углов любого треугольника — 180°."}
]
```

- `correct` — номер правильного варианта **с нуля**. 3–4 варианта, все разные, правдоподобные.
- Ограничения Telegram: вопрос ≤ 300 символов, вариант ≤ 100, пояснение ≤ 200.
- Вопросы — на понимание и типичные ошибки, а не только на определения. Формулы — обычным текстом (x², √, ≠).

## Видео (`videos.md`)

2–4 видео по теме урока (YouTube и т. п.), которые реально помогут: понятная лекция, разбор задач, интересные подробности.
- Ищи поиском и **проверь, что ссылка существует** и видео именно про эту тему. Не выдумывай ссылки; не нашёл хорошего — меньше видео.
- Формат строки: `- [Название](ссылка) — канал, длительность; одной фразой, чем полезно.`

## Задача «ответь на вопросы»

1. `git pull origin master`. В `questions/` найди `<id>.json` без `<id>.answer.md`.
2. Прочитай вопрос и материалы урока из `lesson_folder` (konspekt.md, transcript.txt, materials.pdf); если папки нет — отвечай по теме вопроса.
3. Напиши `questions/<id>.answer.md`: понятно, по шагам, с примером; для задач — полное решение. Без упоминаний ИИ.
4. Закоммить и запушь в `master` (как выше). Сервер перешлёт ответ в Telegram.
