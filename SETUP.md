## ✅ Шаг 1. Ключ Claude API (10 мин)
1. Откройте [platform.claude.com](https://platform.claude.com) → зарегистрируйтесь (аккаунт взрослого).
2. **Settings → Billing → Add funds** → $10.
3. **Settings → Limits** → поставьте месячный лимит, например **$30** — больше не спишется.
4. **Settings → API Keys → Create Key** → скопируйте ключ (`sk-ant-...`) в заметки. Его показывают **один раз**.

## ✅ Шаг 2. Сервер (10 мин)
1. [console.hetzner.cloud](https://console.hetzner.cloud) → регистрация (аккаунт взрослого; Hetzner может попросить подтвердить личность — это нормально, иногда занимает время, поэтому начните с этого шага пораньше).
2. **New project → Add Server**:
   - Location: **Helsinki** или **Falkenstein**
   - Image: **Ubuntu 24.04**
   - Type: **Shared vCPU → CX33** (4 vCPU, 8 GB)
   - Networking: оставьте **Public IPv4** включённым
   - SSH key: можно пропустить — тогда пароль root придёт на почту
3. **Create & Buy now**. Скопируйте **IP-адрес** сервера.

## ✅ Шаг 3. Установка (5 мин работы + ~10 мин ожидания)
1. Подключитесь к серверу **с компьютера**: откройте «Терминал» (Mac) или «PowerShell» (Windows) и введите `ssh root@IP-сервера` → «yes» → пароль из письма (при вводе он не отображается — это нормально). Hetzner может сразу попросить сменить пароль — придумайте новый.
   *Запасной вариант:* кнопка **>_ (Console)** у сервера в Hetzner — терминал в браузере, но вставка текста там может не работать, команду придётся набрать вручную.
2. Вставьте одну команду:
   ```
   curl -fsSL https://raw.githubusercontent.com/MissEmily10/StudyingTool/master/install.sh | bash
   ```
3. Скрипт спросит:
   - **имя для бота** (так он будет подписан в вебинаре — например, ваши имя и фамилия);
   - **логин и пароль** для сайта (Enter — придумает пароль сам и покажет в конце);
   - **ключ Claude** из шага 1.
4. Скрипт проверит, что с сервера открываются MTS Link, Claude API и электронный журнал (должны быть ✓), и через ~10 минут покажет адрес сайта, логин и пароль. **Сохраните их.**

## ✅ Шаг 4. Проверка (5 мин)
1. Откройте `http://IP-сервера:8000` с телефона → логин/пароль.
2. «Новый урок» → предмет «Биология», в «Материалы» вставьте ссылку на PDF из журнала (например, вчерашнюю презентацию), без ссылки на вебинар → «Создать».
3. Через 1–2 минуты должен появиться конспект → кнопка «PDF для печати». Если всё ок — система работает. 🎉

## 📅 Завтра на уроках
- **Перед каждым уроком** (можно утром сразу на весь день): «Новый урок» → предмет → **ссылка на комнату MTS Link** → «по расписанию» + время начала. Бот зайдёт сам за 2 минуты.
- **Во время урока** на странице урока виден скриншот того, что видит бот. Если он застрял на входе — сделайте скриншот страницы и пришлите мне, поправлю.
- **Подстраховка:** первые дни параллельно пишите урок на телефон. Если бот не справится — загрузите файл в «Или уже есть запись», конспект всё равно будет.
- Конспект появится примерно через час после урока (сначала распознаётся речь, потом пишется конспект).

## 🆘 Если что-то не так
- Сайт не открывается → в консоли сервера: `cd /opt/StudyingTool && docker compose logs --tail 50` — пришлите мне вывод.
- Поменять настройки (имя бота, пароль, ключ) → `nano /opt/StudyingTool/.env`, затем `cd /opt/StudyingTool && docker compose up -d`.
- Обновить приложение после моих исправлений → снова команда из шага 3.2.
