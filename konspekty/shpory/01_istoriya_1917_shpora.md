# Россия в 1917 г. — шпора

**Причины кризиса:** затяжная война, поражения, рост цен, перебои с хлебом, «министерская чехарда» (4 премьера за 1916), распутинщина, Николай II — главнокомандующий.

## Февраль (ст. стиль, +13 дн.)
| Дата | Событие |
|---|---|
| 18.02 | Стоп Путиловского завода |
| 23.02 (8.03) | Работницы: «Хлеба!» |
| 25.02 | Николай II: «прекратить беспорядки» |
| 27.02 | Восстание войск; Врем. комитет Думы (**Родзянко**) + **Петросовет** (**Чхеидзе**) |
| 2.03 | Отречение в пользу брата **Михаила** |
| 3.03 | Михаил отказался → решит **Учредительное собрание** |

**Двоевластие:** Временное правительство (власть формально) ↔ Петросовет (армия, рабочие).
**Приказ № 1** (1.03, Петросовет): солдатские комитеты, оружие у солдат → развал дисциплины.

## Временное правительство
- Главы: **Львов** (март–июль) → **Керенский** (июль–окт.).
- Сделали: амнистия, свободы, отмена смертной казни, монополия на хлеб, всеобщее избир. право.
- **Отложили:** выход из войны, землю (до Учр. собрания), 8-часовой день.

## Кризисы «А-И-И-К»
| Кризис | Повод | Итог |
|---|---|---|
| Апрельский | Нота **Милюкова** (война до победы) | Уход Милюкова и Гучкова, 1-я коалиция (5.05) |
| Июньский | Съезд Советов; демонстрация 18.06 | Наступление на фронте |
| Июльский | Уход кадетов, неудачи | Арест большевиков, Ленин → Финляндия, премьер **Керенский** |
| Корниловский (авг.) | Генерал **Корнилов** идёт на Петроград | Разгромлен без боя → **большевизация Советов**; 1.09 — республика |

**Партии:** эсеры — самые массовые (500 тыс.); большевики весной ≈24 тыс.
**Апрельские тезисы** (Ленин, 4.04): «Никакой поддержки Временному правительству!», «Вся власть Советам!»

## Октябрь
- 10.10 ЦК за восстание 10:2 (против — **Каменев, Зиновьев**).
- 12.10 **ВРК** при Петросовете (рук. **Троцкий**).
- 25.10 «Аврора» 21:40 → 26.10 02:10 арест правительства (Антонов-Овсеенко).
- **II съезд Советов:** декреты **о мире** (без аннексий и контрибуций), **о земле** (конфискация без выкупа), **о власти**; **СНК**: Ленин, Троцкий (ин. дела), Рыков, Сталин (нац.).

**Февраль — стихийный, Октябрь — подготовленный.**
