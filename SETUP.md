# Запуск StudyTool — план на вечер (~30 минут)

## Как это работает (без Claude API)

```
Вебинар MTS Link ──► сервер: бот записывает звук ──► распознаёт речь (бесплатно)
                                   │
                                   ▼
                   GitHub: lessons/<урок>/transcript.txt (+ презентация)
                                   │
                                   ▼
        Claude в вашей обычной подписке (по расписанию или по просьбе):
        пишет konspekt.md с дополнениями из интернета
                                   │
                                   ▼
          сервер забирает конспект ──► сайт: просмотр, правка, PDF A5×2
```

Платного API нет: конспекты пишет Claude в той подписке, где вы со мной сейчас общаетесь.

## 💰 Сколько это стоит

| Что | Цена | Комментарий |
|---|---|---|
| Сервер, **4 ядра / 8 ГБ / 80 ГБ**, например Timeweb Cloud «Cloud 80» | **~1800–2000 ₽/мес** | Оплата в рублях. Конспект готов через ~1 час после урока |
| …или **2 ядра / 4 ГБ** | ~в 2 раза дешевле | Распознавание вдвое медленнее (~2–3 часа после урока) |
| Распознавание речи | 0 | Прямо на сервере |
| Конспекты | 0 сверху | Входит в вашу подписку Claude (тратит её лимиты) |
| GitHub | 0 | |
| **Итого** | **~1000–2000 ₽/мес** | только сервер |

Сервер лучше взять **в России** (MTS Link и электронный журнал — российские сайты, из России они открываются надёжнее). Почасовая оплата: если не понравится — удалите сервер, спишется только за отработанные часы.

> Аккаунт у хостинга, скорее всего, нужно оформить на взрослого (18+) — попросите родителей.

## ✅ Шаг 1. Токен GitHub (5 мин, можно с телефона)
Нужен, чтобы сервер мог класть расшифровки в репозиторий и забирать конспекты.
1. github.com → аватарка → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Name: `studytool-server`, Expiration: **1 год**.
3. Repository access: **Only select repositories → StudyingTool**.
4. Permissions → Repository permissions → **Contents: Read and write**.
5. **Generate token** → скопируйте `github_pat_...` в заметки (показывают **один раз**).

## ✅ Шаг 2. Сделать репозиторий закрытым (1 мин, рекомендую)
Сейчас он открытый — а туда будут попадать расшифровки уроков.
github.com/MissEmily10/StudyingTool → **Settings → General → Danger Zone → Change visibility → Private**.
(Скрипт установки это учитывает: если репозиторий закрыт, он спросит токен из шага 1.)

## ✅ Шаг 3. Сервер (10 мин)
1. Зарегистрируйтесь у хостинга (например, [timeweb.cloud](https://timeweb.cloud)) и пополните баланс.
2. Создайте сервер: **Ubuntu 24.04**, **4 vCPU / 8 ГБ RAM / 80 ГБ** (или 2 / 4 ГБ подешевле), регион — Москва или Санкт-Петербург, публичный IPv4.
3. Запишите **IP-адрес** и **пароль root** (придут на почту или видны в панели).

## ✅ Шаг 4. Установка (5 мин + ~10 мин ожидания)
1. С компьютера: «Терминал» (Mac) или «PowerShell» (Windows) → `ssh root@IP-сервера` → `yes` → пароль (при вводе не отображается — это нормально).
   *С телефона:* в панели хостинга у сервера есть «Консоль» в браузере (но вставка текста там может не работать).
2. Вставьте одну команду:
   ```
   curl -fsSL https://raw.githubusercontent.com/MissEmily10/StudyingTool/master/install.sh | bash
   ```
   > Если уже сделали репозиторий закрытым, эта ссылка не откроется. Тогда вместо неё:
   > ```
   > git clone https://x-access-token:ВАШ_ТОКЕН@github.com/MissEmily10/StudyingTool.git /opt/StudyingTool && bash /opt/StudyingTool/install.sh
   > ```
3. Скрипт спросит: **имя для бота** (так он подписан в вебинаре), **логин и пароль сайта** (Enter — придумает сам), **токен GitHub** из шага 1.
4. Проверит, что открываются MTS Link, GitHub и электронный журнал (должны быть ✓), и через ~10 минут покажет **адрес сайта, логин и пароль — сохраните их**.

## ✅ Шаг 5. Проверка (5 мин)
1. Откройте `http://IP-сервера:8000` с телефона → логин/пароль.
2. «Новый урок» → предмет → «Или уже есть запись» → любой короткий файл (голосовое/видео с телефона) → «Создать».
3. Через пару минут статус станет **«Ждёт конспекта от Claude»**, а в GitHub появится папка `lessons/...` — значит, всё работает.
4. Напишите мне: **«сделай конспекты»** — я соберу конспект, и через ~3 минуты он появится на сайте с кнопкой PDF. 🎉

## 📅 На уроках
- **Утром или перед уроком:** «Новый урок» → предмет, тема → **ссылка на комнату MTS Link** → «по расписанию» + время. Бот зайдёт сам за 2 минуты до начала.
- Можно сразу вставить **ссылку на презентацию** из электронного журнала и в «Что задали» — что просил учитель.
- **Во время урока** на странице урока виден скриншот того, что видит бот. Застрял на входе — пришлите мне скриншот страницы, поправлю.
- **Подстраховка первые дни:** параллельно пишите урок на телефон; если бот не справится — загрузите файл в «Или уже есть запись».

## ✍️ Как появляются конспекты
- **Автоматически:** по будням в 17:00 (МСК) я сама захожу в репозиторий и делаю конспекты всех новых уроков. Расписание видно и меняется в claude.ai → Code → Routines.
- **Когда угодно вручную:** откройте Claude Code с этим репозиторием и напишите «сделай конспекты».
- **Совсем без GitHub:** на странице урока откройте «расшифровку», отправьте её мне в любой чат, готовый текст вставьте в поле «Вставить конспект».

## 🆘 Если что-то не так
- Сайт не открывается → на сервере: `cd /opt/StudyingTool && docker compose logs --tail 50` — пришлите мне вывод.
- Поменять имя бота / пароль / токен → `nano /opt/StudyingTool/.env`, затем `cd /opt/StudyingTool && docker compose up -d`.
- Обновить приложение после моих исправлений → `bash /opt/StudyingTool/install.sh`.
