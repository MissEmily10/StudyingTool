# Средства выразительности

## Тропы (переносное значение)
| | Ключ | Пример |
|---|---|---|
| **Эпитет** | образное определение | **усталая** нежность |
| **Метафора** | скрытое сравнение | костёр рябины |
| **Олицетворение** | неживое = живое | ветер поёт |
| **Сравнение** | как, точно, словно | **точно** небо |
| **Гипербола** | преувеличение | с горы на гору шагает |
| **Литота** | преуменьшение | мужичок с ноготок |
| **Оксюморон** | несочетаемое | звонкая тишина |
| **Ирония** | в обратном смысле | «умник» о глупом |

## Синтаксис (построение)
| | Ключ |
|---|---|
| **Анафора** | одинаковое **начало**: «Не напрасно… / Не напрасно…» |
| **Эпифора** | одинаковый **конец**: «…ты, / …ты» |
| **Параллелизм** | одинаковое строение: «посылают — иду, дают — беру» |
| **Градация** | нарастание: жалуются → негодуют → вопиют |
| **Антитеза** | противопоставление: тесно — просторно |
| **Инверсия** | обратный порядок: «Невы державное теченье» |
| **Риторич. вопрос / обращение** | вопрос без ответа; «Сердце, сердце!» |
| **Вопросно-ответная форма** | сам спросил — сам ответил |
| **Однородные члены** | перечисление |
| **Парцелляция** | «Он ушёл. Ночью. Один.» |
| **Умолчание** | «Если бы я знал…» |

**Лексика:** антонимы, синонимы, фразеологизмы, разговорные/устаревшие слова. **Фонетика:** аллитерация (согласные), ассонанс (гласные).

# Грамматические ошибки (ЕГЭ-8)

| Тип | ❌ | ✅ |
|---|---|---|
| **Приложение в кавычках** не склоняется при родовом слове | в гостинице «Москве» | в гостинице «**Москва**» (но: в «Москве» — без слова «гостиница») |
| **Причастный оборот** — не разрывать, согласовать | Приготовленные оладьи мамой | **Оладьи, приготовленные мамой,** / Приготовленные мамой оладьи |
| **Деепричастный оборот** — действие делает **подлежащее** | Выполнив условия, договор был подписан | **Выполнив условия, стороны подписали** договор |
| **Подлежащее + сказуемое** | Часть архива сгорели | Часть архива **сгорела**; Кто из вас **знает** |
| **Косвенная речь** — без «я», «ты» говорящего | Павел сказал, что я приду | Павел сказал, что **он придёт** |
| **Предлог + падеж** | согласно приказа, по приезду | согласно, благодаря, вопреки **+ дат.**: согласно **приказу**; по **приезде**, по **окончании** |
| **Управление** | оплатить за проезд; рецензия о книге | оплатить **проезд**; рецензия **на** книгу; отзыв **о** книге |
| **Однородные члены** | любить и гордиться сыном; не только в школе, но и дома учился | любить **сына** и гордиться **им**; учился не только в школе, но и дома |
| **Сложное предложение** | Он спросил, что придёт ли | Он спросил, придёт **ли** |
| **Числительные** | двухсот (в предл.), трое подруг | о **двухстах**; **три** подруги (собир. не с ж. р.); **обеим** девочкам |
| **Время глаголов** | Он пишет и ответил | Он **писал и ответил** |

**Как искать:** нашли оборот → проверить, кто действует; нашли кавычки → нет ли родового слова; нашли «часть / большинство / кто» → сказуемое в ед. ч.
