## Тип 12. Задача на население
| Что найти | Формула |
|---|---|
| **Естественный прирост (ЕП)** | рождённые − умершие |
| **Изменение численности за год X** | Н на 1 янв. (X+1) − Н на 1 янв. X |
| **Миграционный прирост (МП)** | **изменение численности − ЕП** |
| **ЕП в ‰** | ЕП ÷ среднегодовая численность × 1000 |
| **Общий прирост** | ЕП + МП |

⚠ Берём **1 января следующего года**, а не среднегодовую. Минус на минус → плюс!

**Карточка (2013):**

1. 1 118 915 − 1 119 170 = **−255**
2. −255 − (−5021) = −255 + 5021 = **4766**

→ **миграционный прирост 4766 чел.** (уехало меньше, чем приехало)

## Тип 15. Почему это рациональное природопользование
Шаблон: «**что делают** → **какой ресурс бережём / какое загрязнение убираем**».

- вторичное сырьё (макулатура, металлолом) → **меньше рубят лес / добывают руду**;
- переработка отходов → **меньше свалок**, не жгут мусор → **чище воздух**;
- оборотное водоснабжение, очистные → **меньше загрязнения рек**;
- лесопосадки, рекультивация карьеров → **ресурс восстанавливается**.

**Карточка:** картон из макулатуры → **экономятся лесные ресурсы** (+ меньше отходов на свалках).

## Тип 17. Выбрать точку зрения и доказать
**Цепочка из 2–3 звеньев:** действие → что меняется → как это влияет на проблему.

**«Солнечные ЭС помогают»:**

1. СЭС не сжигают топливо → **нет выбросов CO₂** (парниковых газов);
2. меньше парниковых газов → **слабее парниковый эффект**;
3. → **глобальное потепление замедляется**.

**«Не помогают»:**

1. производство панелей требует **много электроэнергии**;
2. её дают ТЭС → **выбросы CO₂**;
3. → парниковый эффект усиливается (+ панели трудно утилизировать, работают только днём/в солнечных районах).

⚠ Выбери **одну** сторону, пиши **2 довода** связно (= 2 балла). Слова-маркеры: «так как», «поэтому», «следовательно».
