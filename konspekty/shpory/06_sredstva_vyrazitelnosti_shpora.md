# Средства выразительности (ЕГЭ-26) — шпора

**Рецензия:** «троп» → тропы · «лексическое средство» → лексика · «приём / синтаксическое средство» → синтаксис (по номерам предложений) · «звукопись» → фонетика.

## Тропы (переносное значение)
| Троп | Ключ | Пример |
|---|---|---|
| Эпитет | образное определение | хрустальный голос |
| Метафора | скрытое сравнение | костёр рябины |
| Олицетворение | неживое = живое | лес уснул |
| Сравнение | как, словно, будто; тв. падеж | летел стрелой |
| Метонимия | по смежности | читать Пушкина |
| Синекдоха | часть ↔ целое | все флаги в гости |
| Гипербола / литота | больше / меньше | море слёз / с ноготок |
| Ирония | наоборот | «умная» голова (ослу) |
| Перифраз | описание вместо названия | царь зверей |
| Оксюморон | несочетаемое | звонкая тишина |
| Аллегория | понятие в образе | лиса — хитрость |

## Лексика (выбор слов)
**Синонимы / антонимы** (+ **контекстные**: «слово и дело») · **фразеологизмы** · **разговорная** / **просторечная** / **книжная** / **высокая** · **архаизмы** (очи → глаза) ≠ **историзмы** (кольчуга) · **неологизмы** · **диалектизмы** · **профессионализмы** · **термины** · **оценочная** лексика · **лексический повтор**.

## Фонетика (звуки)
**Аллитерация** — со**гла**сные · **ассонанс** — **гла**сные · **звукоподражание** — тик-так · звукопись, рифма, ритм.

**Ловушки:** оксюморон (в словосочетании) ≠ антитеза (в фразе) · антонимы (слова) ≠ антитеза (приём) · фразеологизм (готовый) ≠ метафора (авторская).
