# Россия в 1917 г. — шпора

**Причины кризиса:** затяжная война, поражения, рост цен, перебои с хлебом, «министерская чехарда» (4 премьера за 1916), распутинщина, Николай II — главнокомандующий.

## Февраль (ст. стиль, +13 дн.)
| Дата | Событие |
|---|---|
| 18.02 | Стоп Путиловского завода |
| 23.02 (8.03) | Работницы: «Хлеба!» |
| 25.02 | Николай II: «прекратить беспорядки» |
| 27.02 | Восстание войск; Врем. комитет Думы (**Родзянко**) + **Петросовет** (**Чхеидзе**) |
| 2.03 | Отречение в пользу брата **Михаила** |
| 3.03 | Михаил отказался → решит **Учредительное собрание** |

**Двоевластие:** Временное правительство (власть формально) ↔ Петросовет (армия, рабочие).
**Приказ № 1** (1.03, Петросовет): солдатские комитеты, оружие у солдат → развал дисциплины.

## Временное правительство
- Главы: **Львов** (март–июль) → **Керенский** (июль–окт.).
- Сделали: амнистия, свободы, отмена смертной казни, монополия на хлеб, всеобщее избир. право.
- **Отложили:** выход из войны, землю (до Учр. собрания), 8-часовой день.

## Кризисы «А-И-И-К»
| Кризис | Повод | Итог |
|---|---|---|
| Апрельский | Нота **Милюкова** (война до победы) | Уход Милюкова и Гучкова, 1-я коалиция (5.05) |
| Июньский | Съезд Советов; демонстрация 18.06 | Наступление на фронте |
| Июльский | Уход кадетов, неудачи | Арест большевиков, Ленин → Финляндия, премьер **Керенский** |
| Корниловский (авг.) | Генерал **Корнилов** идёт на Петроград | Разгромлен без боя → **большевизация Советов**; 1.09 — республика |

**Партии:** эсеры — самые массовые (500 тыс.); большевики весной ≈24 тыс.
**Апрельские тезисы** (Ленин, 4.04): «Никакой поддержки Временному правительству!», «Вся власть Советам!»

## Октябрь
- 10.10 ЦК за восстание 10:2 (против — **Каменев, Зиновьев**).
- 12.10 **ВРК** при Петросовете (рук. **Троцкий**).
- 25.10 «Аврора» 21:40 → 26.10 02:10 арест правительства (Антонов-Овсеенко).
- **II съезд Советов:** декреты **о мире** (без аннексий и контрибуций), **о земле** (конфискация без выкупа), **о власти**; **СНК**: Ленин, Троцкий (ин. дела), Рыков, Сталин (нац.).

**Февраль — стихийный, Октябрь — подготовленный.**

# Химия клетки — шпора

## Белки
- Мономер — **α-аминокислота** (NH₂ + COOH + R), 20 видов, **амфотерны**.
- **Пептидная связь** −CO−NH− (выделяется H₂O).

| Структура | Что | Связи |
|---|---|---|
| 1° | порядок АК | пептидные |
| 2° | α-спираль / β-слой | водородные |
| 3° | глобула | Н-, ионные, **S–S** |
| 4° | несколько цепей (гемоглобин) | как в 3° |

- **Денатурация** — потеря 2°–4° (t, pH); 1° цела → возможна ренатурация. **Деструкция** — разрушение 1°.
- Функции: ферменты, гормоны (инсулин), транспорт (гемоглобин), защита (антитела, интерферон), движение (актин, миозин), структура (коллаген, кератин), запас (казеин), рецепторы.

## Ферменты
Белки-катализаторы; **активный центр**; специфичность («ключ–замок»); зависят от t и pH. **Апофермент** (белок) + **кофермент** (витамин, металл) = активный фермент.

## Нуклеиновые кислоты
Нуклеотид = **фосфат + пентоза + азот. основание**. Связь — **фосфодиэфирная** (5′→3′).

| | ДНК | РНК |
|---|---|---|
| Цепи | 2 (спираль) | 1 |
| Сахар | дезоксирибоза | рибоза |
| Основания | А, **Т**, Г, Ц | А, **У**, Г, Ц |

- Пурины: **А, Г**; пиримидины: **Т, Ц, У**.
- **Комплементарность:** А=Т (2 Н-связи), Г≡Ц (3). **Чаргафф:** А=Т, Г=Ц, А+Г=Т+Ц.
- Пример: А=20% → Т=20%, Г=Ц=30%.
- РНК: **иРНК** (копия гена), **тРНК** («клевер», несёт АК), **рРНК** (рибосомы). Уотсон и Крик, 1953.

## АТФ
Аденин + рибоза + **3 фосфата**, **2 макроэргические связи**. АТФ → АДФ + Ф ≈ **40 кДж**.

## Углеводы
Моно (глюкоза, фруктоза, рибоза) → ди (сахароза = глю+фру, лактоза = глю+гал, мальтоза = глю+глю) → поли (**крахмал** — растения, **гликоген** — животные/грибы, **целлюлоза** — стенка, **хитин**). 1 г → **17,6 кДж**.

## Липиды
Гидрофобны. Жир = глицерин + 3 жирные кислоты; **фосфолипиды** → бислой мембран; стероиды (холестерин, гормоны, вит. D). 1 г → **38,9 кДж**; теплоизоляция; метаболическая вода.

## Осмос
Вода через полупроницаемую мембрану → туда, где **концентрация выше**.
| Раствор | Эритроцит | Растит. клетка |
|---|---|---|
| Гипотонич. | лопается (гемолиз) | тургор |
| Изотонич. (0,9% NaCl) | норма | норма |
| Гипертонич. | сморщивается | **плазмолиз** |

# Gerunds / Infinitives / Collocations — шпора

## + -ing
**enjoy, avoid, mind, suggest, consider, deny, admit, finish, keep, practise, risk, miss, imagine, give up, put off, can't stand, can't help**
- после предлогов: *good at drawing*
- *it's no use / no point in / worth* + -ing
- **to = предлог:** *look forward to, be/get used to, object to, when it comes to* + **-ing**

## + to-inf
**agree, decide, hope, plan, promise, refuse, manage, afford, offer, expect, seem, pretend, learn, would like/love/prefer**
- цель: *went out to buy*; *too cold to…*, *old enough to…*; *what to say*
- **V + obj + to:** *want/ask/tell/advise/allow/persuade/remind sb to do*

## Без to
модальные; **make / let** sb do; *had better*, *would rather*.
⚠ пассив: *was made **to** apologise*

## Смысл меняется
| | -ing (прошлое) | to (будущее/цель) |
|---|---|---|
| remember | помню, что сделал | не забыть сделать |
| forget | забыть, как было | забыть сделать |
| stop | бросить делать | остановиться, чтобы |
| try | попробовать (эксперимент) | стараться |
| regret | жалею, что сделал | с сожалением сообщаем |
| go on | продолжать то же | перейти к новому |
| mean | означать | намереваться |

**see/hear sb do** — целиком; **doing** — процесс.

## Collocations
| MAKE | DO |
|---|---|
| a decision, a mistake, an effort, progress, money, friends, a mess, a noise | homework, the shopping, research, your best, exercise, a favour, harm/good |

**take** a photo/risk/exam/part; **pay** attention/a visit; **keep** a secret/promise; **break** a promise/the law; **tell** a lie; **heavy** rain/traffic; **highly** unlikely; **deeply** concerned; **fully** aware; **bitterly** cold; **absolutely** (не very) exhausted.
